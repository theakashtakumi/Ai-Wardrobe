# AI Wardrobe

A personal AI-powered wardrobe and outfit recommendation system.

## Project Goal

AI Wardrobe is designed to understand a user's:

- Clothing collection
- Personal style
- Body and fit preferences
- Color preferences
- Lifestyle
- Weather
- Occasion
- Outfit history

and provide personalized outfit recommendations.
